# A+B 组合选品系统 — 使用说明

## 项目路径

```
D:\auto_video\web-platform
```

## 启动步骤（按顺序）

### 1. 启动 Chrome（爬虫用）

先关闭所有 Chrome 窗口，然后运行：

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="D:\auto_video\web-platform\.chrome-profile" --no-first-run --no-default-browser-check
```

### 2. 启动 PostgreSQL 和 Redis

如果有 Docker：

```powershell
cd D:\auto_video\web-platform
docker compose up -d postgres redis
```

如果没有 Docker，确保 Windows 服务中 PostgreSQL 和 Redis 已启动。

### 3. 启动后端 API

```powershell
cd D:\auto_video\web-platform
.\.venv\Scripts\python.exe -c "import asyncio, sys; sys.platform=='win32' and asyncio.set_event_loop_policy(asyncio.WindowsProactorEventLoopPolicy()); import uvicorn; uvicorn.run('backend.main:app', host='127.0.0.1', port=8000)"
```

### 4. 启动 Worker

```powershell
cd D:\auto_video\web-platform
.\.venv\Scripts\python.exe -m arq backend.workers.settings.WorkerSettings
```

### 5. 启动前端

```powershell
cd D:\auto_video\web-platform
npm --prefix frontend run dev
```

## 访问地址

| 服务 | 地址 |
|---|---|
| 前端界面 | http://localhost:3000 |
| 后端 API | http://localhost:8000 |
| API 文档 | http://localhost:8000/docs |

## 一键启动

也可以直接运行：

```powershell
cd D:\auto_video\web-platform
.\启动.ps1
```

会弹出 3 个终端窗口分别启动后端、Worker 和前端。

## 常用命令

```powershell
# 运行测试
.\.venv\Scripts\python.exe -m pytest tests -q

# 数据库迁移
.\.venv\Scripts\alembic.exe -c backend/migrations/alembic.ini upgrade head
```
