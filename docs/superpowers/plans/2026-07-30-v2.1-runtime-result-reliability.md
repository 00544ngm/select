# V2.1 运行与结果可信度闭环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让每一条新建假设/批量推荐任务都由版本一致的 V2.1 Worker 执行，并让零候选、待补证据和合格候选在 API、页面、JSON 与 Excel 中得到一致、可审计的表达。

**Architecture:** 使用 `app/core/runtime_contract.py` 作为 API、Worker 和模型输出共享的唯一契约来源；任务创建时固化期望版本和代码 revision，Worker 在任何采集或供应商调用前校验。`HypothesisService` 负责严格输出版本校验和最多一次的零方向遗漏复核，`backend/application/result_quality.py` 负责业务状态统计与完成前质量验证，UI/Excel 只展示已验证的结果载荷而不重算业务判断。

**Tech Stack:** Python 3.11、FastAPI、Pydantic、SQLAlchemy、ARQ/Redis、pandas/openpyxl、Next.js 15、React 19、TypeScript、Vitest、PowerShell、pytest、Ruff。

- [ ] **Step 6：实现状态汇总与完成前质量验证器**

`backend/application/result_quality.py` 提供纯函数：

```python
from collections import Counter
from dataclasses import dataclass

RESULT_WITH_CANDIDATES = "completed_with_qualified_candidates"
RESULT_NEEDS_EVIDENCE = "completed_needs_evidence"
RESULT_NO_CANDIDATES = "completed_no_qualified_candidates"


class ResultQualityError(RuntimeError):
    code = "RESULT_QUALITY_INVALID"
    retryable = False

    def __init__(self, message: str) -> None:
        self.message = message
        super().__init__(message)


@dataclass(frozen=True)
class ResultSummary:
    result_status: str
    result_message: str
    raw_direction_count: int
    qualified_direction_count: int
    hold_direction_count: int
    rejected_direction_count: int
    rejection_summary: dict[str, int]


def summarize_directions(directions: list[dict]) -> ResultSummary:
    pass_count = sum(item.get("execution_status") == "pass" for item in directions)
    hold_count = sum(item.get("execution_status") == "hold" for item in directions)
    reject_count = sum(item.get("execution_status") == "reject" for item in directions)
    rejection_counts = Counter(
        code
        for item in directions
        if item.get("execution_status") == "reject"
        for code in item.get("rejection_codes", [])
    )
    status = (
        RESULT_WITH_CANDIDATES if pass_count
        else RESULT_NEEDS_EVIDENCE if hold_count
        else RESULT_NO_CANDIDATES
    )
    messages = {
        RESULT_WITH_CANDIDATES: "分析已完成，发现达到高粘性门槛的候选，请按候选最终动作执行。",
        RESULT_NEEDS_EVIDENCE: "发现潜在方向，但当前不可执行，请先补齐兼容、安全或商品类型证据。",
        RESULT_NO_CANDIDATES: "分析已完成，未发现达到高粘性门槛的辅品，不建议为了凑数量强行组合。",
    }
    return ResultSummary(
        result_status=status,
        result_message=messages[status],
        raw_direction_count=len(directions),
        qualified_direction_count=pass_count,
        hold_direction_count=hold_count,
        rejected_direction_count=reject_count,
        rejection_summary=dict(sorted(rejection_counts.items())),
    )
```
