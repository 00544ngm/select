# 结果页中英双语展示设计

## 目标

提升组合分析结果页的中文可读性，同时保留模型原始英文值，且不改变评分、采集、数据库或供应商协议。

## 设计

- 在 `frontend/lib/result-labels.ts` 集中提供枚举、深度字段、定价策略和关键词显示格式化函数。
- 结果组件调用 formatter：组合类型、购买方向、证据等级、推荐等级、执行状态和深度分析键统一显示为“中文（英文原值）”。
- 搜索词保留完整英文短语，按已有关键词字段排序并使用中文分隔符；没有可靠翻译时不生成臆测中文。
- 深度分析对象递归渲染，数组、布尔值和嵌套对象使用可读文本，原始数据折叠区继续保留。
- 所有显示改动仅作用于 React 展示层，历史 payload 原样读取。

## 验证

- 前端组件测试覆盖枚举、定价、深度字段和关键词显示。
- `npm.cmd run build` 后运行 `npm.cmd run typecheck`。
- 通过当前任务页确认无裸英文键名、双语文本不重叠，分数与推荐状态不变。
