# 链接驱动的高粘性组合推荐设计

日期：2026-07-29
状态：已确认，待实施
适用范围：全品类商品组合推荐

## 1. 目标

用户提供一个主品链接后，系统只围绕该主品分析哪些产品值得一起购买。核心判断是功能、使用、场景和维护上的购买粘性，不判断主品或辅品是否为爆品。

系统需要支持以下组合：

- 强依赖：打印机 + 墨盒
- 功能增强：相机 + 镜头
- 连续使用：咖啡机 + 非食品滤纸
- 保护维护：电器 + 保护壳或清洁工具
- 延伸场景：基于主品实际使用过程发现的、可解释的新搭配

食品、饮料、调味料、食材和需要食用的补充品默认过滤；墨盒、滤芯、电池、刀片等不可食用的耗材不因“耗材”标签被过滤。

## 2. 核心原则

1. 主品事实只来自用户提供的链接及其可验证的页面信息。
2. 辅品必须能解释为主品购买链路中的必要、连续、增强、维护、保护或收纳环节。
3. 同类目但没有购买链路的商品不能进入高粘性结果。
4. “爆品”不属于准入条件，也不参与粘性核心分；市场数据只作为后置验证信息。
5. 推测出的拓展场景必须单独标注成立前提和不确定性，不能伪装为已验证事实。
6. 所有硬过滤、评分和排序由后端确定性逻辑执行，模型只能提供结构化事实、关系解释和候选理由。

## 3. 评分模型

粘性总分为 100 分，独立于市场证据：

| 维度 | 权重 | 判断问题 |
| --- | ---: | --- |
| 功能必要性 | 30 | 没有辅品时，主品是否无法使用或效果明显下降？ |
| 使用连续性 | 25 | 两个产品是否在同一次任务中连续使用？ |
| 场景一致性 | 20 | 是否解决同一真实场景中的连续问题？ |
| 增强、维护和保护 | 15 | 是否提升效果、清洁、维护、寿命、收纳或运输？ |
| 消费者自然联想 | 10 | 消费者是否会自然想到一起购买？ |

评分前执行硬规则：食品过滤、已包含物过滤、不兼容过滤、安全风险过滤、重复功能过滤和无有效购买链路过滤。

推荐等级：

- 90-100：强粘性，优先测试
- 80-89：高粘性，进入测试池
- 70-79：中粘性，观察验证
- 70 以下：弱粘性，不推荐

市场证据另存为 `market_evidence_status`，取值为已验证、部分验证或待验证，不改变上述粘性分。

## 4. 数据流和边界

1. 读取并解析主品链接。
2. 提取标题、品牌、规格、功能、适配限制、使用步骤、产品类型和页面来源时间。
3. 让模型输出候选辅品、关系类型、购买链路、延伸场景、成立前提、风险和搜索词。
4. 后端确定性执行食品过滤、兼容性检查、包装包含检查和评分。
5. 现有 Walmart/Amazon 证据服务只验证候选是否真实存在、搜索需求和竞品基础。
6. 将同一份最终 DTO 保存到 JSON、Excel、历史记录和任务详情。
7. 前端以结构化模块展示，不直接展示嵌套 JSON 或大段原始 URL。

不修改商品数据库、关键词数据库、采集器、供应商调用、判断模式和利润计算模块。

## 5. 输出结构

主品区域：

- 主品标题、来源链接、核心购买任务
- 关键功能、适配限制和使用步骤
- 主品事实来源与采集时间

辅品区域：

- 产品名称、精准搜索词和粘性等级
- 粘性总分与五维分项
- 购买链路：使用前 → 使用主品 → 使用辅品
- 功能关系、使用关系、场景关系、维护/保护关系
- 拓展场景、成立前提和风险
- 食品过滤状态
- 市场证据摘要、来源平台和验证时间

淘汰区域：

- 候选名称
- 淘汰类型
- 可读的具体原因，例如“仅同属厨房类目，没有连续购买链路”或“属于可食用食品，已按规则过滤”。

原始字段只在“查看原始数据”折叠区提供。

## 6. 数据字段

在现有 DTO 兼容基础上增加或规范化：

- `source_url`
- `product_type`
- `food_filter_status`
- `relation_reasons`
- `extended_scenarios`
- `stickiness_score`
- `confidence_level`
- `market_evidence_status`
- `rejection_reason`

旧字段继续保留，历史任务缺少新字段时使用空值和“待验证”展示。

## 7. 错误和证据不足

- 链接无法解析：停止推荐并显示链接解析原因，不猜测主品属性。
- 页面信息不足：保留候选但将可信度标记为待验证，不提升为强粘性。
- 市场验证失败：保留粘性判断，单独显示市场证据失败原因。
- 食品分类不确定：默认进入待验证/过滤队列，不自动推荐。
- 模型输出缺少必需关系理由：该候选不得进入高粘性结果。

## 8. 回归测试

至少覆盖：

- 打印机 + 墨盒：强粘性
- 相机 + 镜头：强粘性
- 电动研磨器 + 黑胡椒：食品过滤
- 电动研磨器 + 清洁刷：中高粘性
- 厨房剪刀 + 量杯：弱粘性或淘汰
- 主品包装已包含的配件：淘汰
- 不兼容型号配件：淘汰
- 非食品耗材（滤芯、电池、刀片）：不因耗材标签被误过滤

验证命令：`py -m pytest -q`、`npm test -- --run`、`npm run typecheck`、`npm run build`。

## 9. 完成标准

- 粘性核心评分不含爆品属性。
- 食品过滤不会误伤非食品耗材。
- 所有输出渠道使用同一最终分和过滤结果。
- 前端可读展示关系链、拓展场景、证据摘要和淘汰原因。
- 全品类回归测试通过，且原有采集、利润和判断流程不回归。
