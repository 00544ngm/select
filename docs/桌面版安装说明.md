# 组合选品控制台桌面版安装说明

## 安装

1. 双击最新的 `组合选品控制台-Setup-0.1.4.exe`。
2. 按安装向导选择安装目录并完成安装；安装过程需要 Windows 管理员确认。
3. 从桌面快捷方式或开始菜单打开“组合选品控制台”。
4. 第一次打开后进入“API 设置”，重新填写并测试需要使用的供应商配置。

桌面版自带 API、单 Worker、Next.js 前端和 Chromium，不需要另外安装 Python、Node.js、Redis、PostgreSQL 或 Chrome。

## 数据位置

桌面数据保存在 `%LOCALAPPDATA%\组合选品控制台`。卸载程序默认保留该目录，重新安装后仍可继续使用本机数据。不要手工修改正在运行的软件数据库。

## 退出

关闭主窗口只会隐藏到系统托盘。需要彻底退出时，在托盘图标菜单中选择“完全退出”。

## 校验

安装包旁的同名 `.sha256` 文件记录安装程序的 SHA-256，发布时以该文件为准。
# 员工电脑注意事项

- 每个 Windows 用户必须在自己的账户中重新录入 API Key、验证并勾选模型。
- 运行数据和日志位于 `%LOCALAPPDATA%\组合选品控制台`，不会写入安装目录。
- 提交超过 15 秒没有收到本地服务响应会自动结束等待并提示重试。
- 发生失败时通过软件的“打开日志”获取 `api.log`、`worker.log`、`frontend.log`。
- 浏览器意外关闭时，软件会在模型调用前自动重启并重试一次，不会重复消耗模型 Token。
- 若自动恢复仍失败，可在任务错误卡片中运行环境检查、打开日志目录和 Windows 安全中心；软件不会关闭安全防护或自动添加排除项。
- 食品硬拦截只读取商品标题和商品类型等主体字段；卖点或描述中的“零食桌”“宠物食品收纳”等使用场景不会再把常规品误判为食品。
