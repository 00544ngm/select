# 准入证据链与员工行动指引验收记录

## 验收结论

本轮已把技术状态转换为员工可执行语言，并强化硬拒绝的证据门槛。历史任务不改写原始数据；证据不完整的旧拒绝仅在展示层解释为“历史判定证据不完整”，建议重新分析。

## 业务行为

- 新任务只有在拒绝代码、对应 blocked 门禁、具体理由、有效事实来源相互一致时，才允许输出硬拒绝。
- 缺少理由或有效事实来源的 blocked 自动降级为待复核。
- 页面统一显示一个当前处理建议，并解释“为什么 / 下一步 / 这意味着”。
- 历史无完整证据的拒绝不会再显示成确定准入失败，也不会暗示该辅品永久不能做。
- 粘性价值分继续保留，不因准入状态被清零。
- Excel 新增“当前处理建议 / 具体原因 / 下一步”，同时保留原始技术字段用于审计。
- 规则适配全品类非食用品；食品、药品、补充剂及宠物食品继续拦截。
